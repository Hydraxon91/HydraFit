# HydraFit 0.13.0

This release is the workout-first redesign of the main screens.

## Train

- A workout now opens on an overview of its targets, with one action to start or
  resume training and the remaining sets in front of you.
- **Replace for this workout** changes one exercise for this occurrence only. The
  saved routine is untouched.
- Finish, Finish partially, Skip and the manual-entry options live in a labeled
  **Workout actions** menu, so the start or review action stays visible.
- Timed sets keep the timer text and its controls readable at larger text sizes.

## Navigation

- One bottom row: **Train**, **Progress** and **Library**. Workout history stays in
  Train, the fatigue map and body weight stay in Progress, and routines and equipment
  stay in Library.
- Settings moved to the toolbar. Choosing another tab closes Settings without saving
  unsaved field edits; saved preferences stay.

## Settings

- Settings is now a hub: Workout preferences, Notifications, Planner engine, Units,
  Backup & data and About, plus a separate **Set up HydraFit** entry. Each page keeps
  the behavior and safeguards it had before.

## Routines and plans

- Routines separates the **Active block** from **Saved routines**. Block progress is
  visible immediately and the per-workout schedule opens behind **View schedule**.
  Archived routines sit behind an **Archived** filter, and Duplicate, Export, Archive
  and Delete moved into a **More actions** menu.
- The routine editor keeps the prescription you need in view and puts Progression,
  Per-set targets, Cluster and superset pairing behind a per-slot **Advanced** toggle.
- **Weekly plan** leads with plan status and contents. Frequency, set counts, automatic
  targets, supersets and dates sit under **Plan configuration**, which starts open when
  there is no plan yet.
- Accepted-plan substitution is now labeled **Change in plan**, distinct from Train's
  one-workout replacement.

## Progress and equipment

- Progress stays exercise-first: the selected exercise with a **Change exercise**
  picker, wrapping filters, and separate sections for the range trend, all-time records
  and recorded sets.
- Body weight leads with **Add measurement** and the trend; goal editing sits behind
  **Edit goal**.
- Equipment leads with the active profile and inventory, groups loading configuration
  with stations, and keeps catalog administration, exclusions and manual baseline
  records in separate sections.

## Editors

- Editors across the app now use a scoped title, a filled primary save action and a
  secondary Cancel, with destructive actions kept apart from save.
- Fixed: the Start training block dialog clipped its "Cancel the current block and
  start this one" label.
- Fixed: a long equipment name could split the adjacent Manage label mid-word.
- Fixed: the workout overview showed a null rep count ("3 × null reps") for a
  force-measured exercise instead of its prescribed newtons.

## Known limitations

- TalkBack, locale variants and rotation were not verified on the changed screens.
- Back from a screen inside a navigation group (for example Fatigue map or Equipment)
  returns to Train rather than that group's own screen.
- The draft editor and occurrence replacement dialog were not exercised on a device in
  this release cycle.
