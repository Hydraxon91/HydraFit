# 0.13.4

## New

- Exercise Progress now has two chart choices: **External load-volume** and
  **Estimated 1RM**. Switch between them without changing the selected exercise,
  date range or station.
- Recorded points are joined by a straight line across days you did not train.
  Dots still mark the days you recorded data, and the line never invents a daily
  value.

## Improved

- A new Quiet Strength visual identity across the app: deep teal actions, calm
  graphite surfaces, clearer workout numbers and matching roundness in light and
  dark themes.
- Progress charts now have readable dates and value labels, with a clearer
  selected range and metric.
- The workout overview, training controls, rest prompt, set editor and Routines
  screens have a clearer hierarchy between primary and secondary actions.
- In the set editor, Save and Cancel stay visible above the keyboard.

## Known limitations

- TalkBack speech, tablet and foldable layouts, pound display, and some
  empty/error journeys have not been checked for the new theme and charts.
- The rest timer uses a slightly smaller type size than the original design
  reference so it does not wrap in the compact training layout.
