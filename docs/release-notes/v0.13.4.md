# 0.13.4

## New

- Exercise Progress now has two chart choices: **External load-volume** and
  **Estimated 1RM**. Switch between them without changing the selected exercise,
  date range or station.
- Recorded points are joined by a straight line across days you did not train.
  Dots still mark the days you recorded data, and the line never invents a daily
  value.

## Improved

- The app now has four tab/rail destinations — Train, Progress, Library and Settings — with
  labels kept visible. Settings is a normal destination instead of a toolbar overlay, and
  reselecting a tab returns its own start screen.
- Library is a hub for Routines and Equipment. Equipment opens five focused pages: Profile &
  loading, Inventory & stations, Exercise catalog, Exclusions and Baseline records.
- Manual logging moved to its own form with a dedicated exercise picker. The form, picker and
  workout controls share the same Logger state, so drafts and running timers survive moving
  between them; session controls and notes remain on Train. A logged set can be repeated
  without reopening the form.
- A new Quiet Strength visual identity across the app: deep teal actions, calm
  graphite surfaces, stronger workout and action hierarchy, clearer workout numbers and
  matching roundness in light and dark themes. Inter is bundled locally, with no font
  download at runtime.
- Settings → About now shows the selected HydraFit mark and opens the complete offline
  third-party notices, including licence texts and source/provenance details.
- Launcher artwork now uses the selected HydraFit logo and mark for adaptive, legacy and iOS
  icons.
- Progress charts now have readable dates and value labels, with a clearer selected range and
  metric.
- The workout overview, training controls, rest prompt, set editor and Routines screens have
  a clearer hierarchy between primary and secondary actions.
- In the set editor, Save and Cancel stay visible above the keyboard.

## Known limitations

- Fold/unfold posture transitions and tablet/foldable edge postures have not been exercised;
  the unfolded foldable, tablet and phone layouts were checked.
- Some empty, error and retry journeys for the new charts have not been exercised.
