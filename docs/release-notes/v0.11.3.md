# HydraFit 0.11.3

This release combines the cluster and manual-cardio work planned for 0.11.3–0.11.4.

## Drop sets and rest-pause

- Add ordered rep and load targets for drop sets or rest-pause clusters in routines.
- Each cluster occupies one prescribed set position; its segments are not extra sets.
- Inspect and correct recorded segment reps, loads and RIR together.
- Log completed segments one at a time, pause with saved work intact, and resume the next segment.
- See incomplete clusters separately in workout summaries and cluster counts separately in
  muscle coverage.

Cluster work does not contribute to ordinary strength records, estimated 1RM, automatic load
progression, modelled fatigue or planner credits. Recorded last-trained information is retained.

## Manual cardio

- Record walking, running, cycling, rowing or Other activities with a start time and duration,
  plus optional distance and notes.
- Review activity history and duration/distance charts independently of resistance workouts.
- Export a separate cardio analysis CSV from Settings. Formula-like notes are prefixed for
  spreadsheet safety without changing your saved notes.

Local backups include cluster and cardio records.
