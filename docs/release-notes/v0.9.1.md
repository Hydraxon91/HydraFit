# HydraFit 0.9.1

This release adds importing workouts from other apps, sharing plans and routines
between installs, and exporting your training history and plans as files.

## New

- **Import workouts from other apps.** Settings → Data transfer can read a CSV
  exported from FitNotes, Strong or Hevy, show what it found, and let you decide
  how each exercise, load and session maps before anything is written. Each source
  workout becomes its own closed session, and sets recorded on the same day can be
  kept together or split into separate sessions. The original sets are kept as
  recorded, and the effective muscle attribution is frozen at import so later
  catalog edits cannot silently reinterpret imported history. Choosing a provider is
  explicit: FitNotes, Strong and Hevy. For Strong, HydraFit reads the export that
  records a weight unit; the newer Strong export leaves the unit out, so HydraFit
  refuses it rather than guess kilograms or pounds.
- **A repeated import cannot double up.** HydraFit remembers what it has already
  imported from each source file. Importing the same file again skips what is
  unchanged, and if the source content changed for something already imported the
  import stops instead of guessing. Deleting an imported workout locally does not
  make a later import silently restore it.
- **Share a routine.** From the Routines screen you can export one routine as a
  `hydrafit-routines` file to send to someone or move to another device. Prescribed
  weights are left out unless you turn that on.
- **Import a routine someone shared.** Opening a routine file shows each exercise
  it needs and what HydraFit will do: use the one you already have, create the
  sender's custom exercise, or point at one of yours. Nothing is decided for you,
  nothing is overwritten, and an import never activates or schedules anything — the
  routines arrive as editable drafts. Exercises that need equipment you have not
  selected are flagged before you commit, not after, and an exercise whose shared
  id clashes with a different one in your library is never silently swapped: you
  choose which to use.
- **Export or print a plan.** Split Builder can export the plan on screen as a
  routine file or save it as a PDF. Both use the plan exactly as displayed: nothing
  is saved or changed by exporting, and prescribed weights follow the same opt-in as
  sharing a routine.
- **Export your training history as CSV.** Settings → Data transfer saves one row
  per recorded set, with kilograms, UTC timestamps, the session it belongs to and
  how the set was timed. Text that a spreadsheet could misread as a formula is
  escaped, so the file opens safely.

## Improved

- The Settings data-transfer area now groups backup, workout import, history CSV
  export and restore together, and each action says what its file is for.

## Upgrade notes

- Nothing is required of you. Your existing routines, plans, schedule and history
  are untouched. This release adds two additive database tables for its import
  ledger, which HydraFit creates when it upgrades on first launch.
- A backup you export from this version still restores in this version and carries
  the import ledger along with the rest of your data.

## Known limitations

- The three import layouts are covered by synthetic fixtures and public sample
  exports, not by exports captured from every app version or device. An import from
  a variant HydraFit cannot read fails with a message instead of guessing, and
  current-version compatibility with each provider is not claimed.
- Imported sessions are local-only. HydraFit does not write back to FitNotes,
  Strong or Hevy, and it does not create or rename exercises to force a match.
- Routine and plan sharing covers prescriptions only. History, personal records,
  notes, credentials, equipment inventories and your schedule state are never
  included in a shared file — that is why a shared file cannot be restored as a
  backup.
- The history CSV is an analysis export, not a backup: personal notes are not
  included and the file cannot be restored into HydraFit.
- Exporting a PDF and writing any of these files needs a platform document picker.
  On a platform without one, HydraFit says so instead of failing after you choose a
  destination.
- Device checks covered a debug emulator build: the document picker, an actual import
  write, the review, mapping and session editors, splitting one source workout into two
  sessions, a repeat import being recognised and skipped, a plan PDF written and its
  rendered page inspected, and a routine exported and imported back were exercised there.
  Dark mode, larger text and everything on iOS were verified by tests, not on a device.
