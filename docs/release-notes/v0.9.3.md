# HydraFit 0.9.3

Automatic backups, password-protected backup files, and timed sets.

## New: automatic backups

- **HydraFit can back itself up automatically.** In Settings → Data transfer, choose a folder and
  turn on automatic backups: about once a day, HydraFit saves a backup there and keeps the seven
  most recent ones, so you always have a recent copy without remembering to export.
- **Back up now** runs the same backup immediately. Files are written to the folder you choose —
  if that folder is synced by a cloud drive, your backups go there too.
- Automatic backups only ever create and remove files HydraFit itself wrote; anything else in the
  folder is left untouched. Turning automatic backups off keeps all existing files.

## New: encrypted backups

- **You can protect backup files with a password.** When exporting, choose "Encrypt with a
  password"; HydraFit asks for that password when you restore the file. Exporting an unencrypted
  file is still possible and clearly labeled.
- **Automatic backups can be encrypted too.** Set a password once in the automatic-backup section
  and every snapshot is sealed with it. The password itself is never stored on your device.
- **A forgotten backup password cannot be recovered** — there is no reset. Keep it somewhere safe.
- If the on-device key that lets automatic backups run unattended is lost, HydraFit asks you to
  re-enter your password to continue; files you already made stay readable with that password.
- Encrypted backups need Android 8 or later. On Android 7, automatic and manual backups stay
  unencrypted.

## New: timed sets and timed prescriptions

- **Exercises can now be logged by time as well as reps.** A set can record a duration, and planned
  targets can prescribe seconds instead of a rep count.
- Timed targets appear in routines, accepted plans and printed plan PDFs, the workout logger
  confirms and edits them like any other set, and preparation steps remember their own timing.
- You can set how long a planned slot should take, and the Logger honors it while logging.

## Improved

- Planner load suggestions now account for exactly when you last trained each exercise, instead of
  assuming every session happened today.

## Notes

- Files from earlier HydraFit versions open normally, and plain backups made here work in older
  versions that know their format; encrypted files need a version with encryption support
  (0.9.3 or later).
- Your data stays on your device: backups are plain files in a folder you choose, and encrypted
  files are readable only with your password.
