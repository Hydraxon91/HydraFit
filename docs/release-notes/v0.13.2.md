# 0.13.2

## Improved

- Setup and execution guidance is now available for every exercise in the
  seeded catalog, not just a subset. Each entry describes how to set up and how
  to perform the movement without prescribing a progression.
- Numbers follow your device's decimal separator. A comma locale accepts `72,5`
  as well as `72.5`, and weights, distances, force readings and plan targets are
  shown with the same separator you type.
- Grouped input such as `1.234,5` is refused instead of guessed, and stored
  values keep their canonical units.
- Routines no longer show a silent empty screen when a read fails. Loaded
  routines and any open editor stay in place, and Retry re-reads without
  changing stored data.
- English remains the baseline language with a clean fallback when the app
  locale is set to a language that has no translated resources yet.

## Known limitations

- Dates and saved/interchange files keep their existing ISO form, so they stay
  unambiguous and portable.
- Loading-inventory plate amounts keep their fixed technical format rather than
  following the locale decimal separator.
- TalkBack speech has not been listened to; accessibility is covered by screen
  semantics rather than audio verification.
- Timed sets remain foreground-only.
