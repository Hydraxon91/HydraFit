# HydraFit 0.10.0

Progression now follows the target you actually trained against.

## What changed

- **Your logged sets remember their target.** When you log a set, HydraFit records the prescription
  you were following — sets, reps or seconds, and the target load — alongside the set. Correcting a
  set later changes what you did, never what you were aiming for.
- **Progression compares like with like.** A completed session only counts toward a streak when it
  matched the target it was performed against. Work performed against a different prescription is
  never stitched together into one streak.
- **Two workouts on one day stay two workouts.** Sessions are compared individually instead of being
  merged by calendar day.
- **Missing evidence is not failure.** If a session's target is unknown — for example a workout that
  was never finished, an imported history entry, or older data recorded before this version — it
  breaks the streak without counting as a missed target, so no weight is taken away on incomplete
  information.
- **Your existing history is left alone.** Older sets keep no recorded target and stay "unknown"
  rather than being compared against whatever plan you happen to have now. Where a scheduled workout
  still clearly records what you were following, that preserved target is used.

Unchanged: the recent-performance window, your manual personal records as a floor, the deload pause,
and the existing streak thresholds and increment cap.

## Backups

Files from earlier versions open normally and restore with no recorded targets, which is treated as
unknown. Backups written here use a newer format (21) that carries the recorded targets, so they
survive a restore or a merge.
