# HydraFit 0.10.1

This release adds **per-set prescriptions** and **progression policies** to your routines and
generated plans, plus a way to record the effort a set is meant to be taken to.

## New

- **Set a different target for each set.** A routine slot can now prescribe an ordered list of sets
  instead of one repeated number, so a warm-up-to-top-set or pyramid session is a real prescription
  rather than a note to yourself.
- **Build a set ladder from a preset.** In the routine editor, open **Per-set targets** on a counted
  slot and choose a shape — straight, ascending load, descending load, or a pyramid that peaks in the
  middle — then set the rep endpoints, the loads and the rounding step. A live preview shows the
  resulting sets before you apply anything, and reopening the slot shows the values you entered.
- **Ask the planner to build the ladder for you.** SplitBuilder has an opt-in for automatic per-set
  generation: choose a shape and a rep range once and generated plans come back with ordered sets.
  Each set's load comes from the same estimated-1RM conversion the planner already uses for your
  logged history, and it only applies to exercises that track an external load.
- **Prescribe how hard a set should be.** A set can carry a prescribed reps-in-reserve (RIR) target
  from 0 to 4. The Logger shows it next to the equivalent RPE, which is the same closeness-to-failure
  scale (`RPE = 10 − RIR`) written the other way round. This is what the set is *meant* to feel like —
  it is never filled in as the effort you actually recorded.
- **Give a routine slot a progression policy.** You can set a rep range and a load step on a routine
  slot, so the app knows the range you want to work inside.

## Improved

- **Per-set targets survive everywhere.** An ordered prescription travels through routine editing,
  starting a block, logging, and both backup/restore and routine sharing, and it is rejected rather
  than reinterpreted by a build that predates it.
- **The Logger shows what each set is for.** A set logged from an ordered slot records the target it
  actually followed, and the Logger displays the prescribed effort and the per-set summary.

## Known limitations

- **The progression suggestion is not shown yet.** The app can compute what a slot's next target
  should be from your recorded history, and that logic is tested, but there is no screen that shows or
  applies it. Setting a policy records your intent; it does not yet change what you are prescribed.
- **The new dialogs and displays have not been checked on a device.** They are covered by automated
  tests, not by a run on an emulator.
- The database changes in this release are covered by automated migration tests, not by upgrading an
  existing installation on a device.
- Bodyweight and timed slots do not carry per-set load targets, and a routine slot's per-set ladder
  must match its own set count.
