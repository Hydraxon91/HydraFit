# HydraFit 0.10.5

Guided workouts and suggested loads get a set of corrections from live use. Nothing in your saved
data, routing or prescriptions changes format.

## Fixed

- **The rest timer keeps running when you edit a set.** Correcting the reps, weight or time of a
  set you just logged, or fixing a workout's time, no longer drops the countdown. It used to
  restart or vanish, leaving you without a rest period.
- **Finishing a guided day closes that workout's session.** Previously the session could stay open,
  so the next set you started was appended to the finished day instead of beginning a new one.
  Finishing or skipping with recorded work now ends its own session.
- **"Edit draft" edits the pending set instead of logging it.** Applying a draft change updates the
  set waiting to be recorded; it does not write a set to your history or start a rest timer. The
  set is recorded only when you log it.

## Improved

- **Completed exercises fold away.** A guided exercise whose prescribed work is done collapses to
  its name and a summary. Remove one of its sets and it opens again, so you can see what you
  changed.
- **Supersets show one set of controls.** Only the exercise whose turn it is has start, log,
  complete and edit controls; the partner is shown for context. Skipping a turn cancels its live
  timing, records nothing, and passes the turn on.
- **Replacement loads come from the exercise you are replacing.** A swap suggestion is calculated
  from that exercise's own recorded sets, not converted from a different exercise's numbers, and it
  is labelled with where the number came from.
- **Dumbbell loads say what they mean.** A load is shown as per hand or per dumbbell instead of a
  doubled total, and your recorded history is read with the same meaning.
- **Suggested loads round to what you can actually build.** Automatic suggestions land on the
  highest load reachable from your saved bars, plates and dumbbells at or below the computed value,
  and say why when no reachable load exists. Previously a suggestion could ask for a weight your
  equipment cannot make.
- **A starting load is one steady number, not your best day.** The baseline now uses a
  session-balanced median of your recent qualifying sets, so a single exceptional session does not
  raise every following prescription.
- **A short, heavy single no longer drives high-rep work.** A manual PR of one or two reps can no
  longer raise the floor for prescriptions of three or more reps.

## Known limitations

- **Guided workouts are strictly sequential.** An exercise or pair later in the workout shows no
  controls until every prescribed set before it is complete. This is intended, but a pair can look
  inert until you reach it.
- **Sessions are matched to a workout by the sets recorded in it.** Live sessions do not store an
  explicit link, so the attribution relies on which sets ended up in which session.
- **Machine and cable-stack suggestions are not rounded to your stack yet.** Rounding covers bars,
  plates and dumbbells; machine identity and stack increments need the upcoming equipment-identity
  work.

## Data and compatibility

No database schema change, no migration and no backup-format change. Existing routines, plans,
history, PRs and backups load exactly as before.
