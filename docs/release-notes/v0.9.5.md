# HydraFit 0.9.5

Merge multiple backups into one device, and see and remove what HydraFit stores.

## New: merge restore

- **You can now add another backup's history to this device** instead of replacing everything.
  Settings → Backup now offers **Merge** beside **Replace**, and shows exactly what merging would
  add, what stays as it is, and which kinds of data a merge does not carry.
- **A merge only ever adds records.** Sessions, their sets, session notes, body-weight days,
  personal records and per-exercise data that this device already has are kept, never overwritten or
  deleted. Merging the same file twice adds nothing, so it is safe to re-run.
- **Unfinished sessions in a backup are skipped** (they would otherwise appear as an open workout
  here), and merged sets are not linked to a scheduled workout in the file. Both are stated in the
  preview before you confirm.
- **Replace restore is unchanged**, including encrypted files: unlock previews the file first, and
  you choose Replace or Merge from there.

## New: storage and data controls

- **Settings → Storage and data shows what HydraFit keeps on this device**: the database size, how
  many automatic snapshots exist (and their size where the folder reports it), the on-device model
  state, and exact counts for each group — workout history, planning data, body and records,
  training setup, custom exercises and settings.
- **Remove one group at a time**, with a confirmation that lists what will be removed and what stays.
  Removing workout history, for example, leaves plans, routines, equipment and your profile alone.
- **Removing everything asks you to type REMOVE.** The exercise catalog, saved credentials, model
  files and backup files stay; HydraFit returns to its setup flow.
- **Back up now is offered in every removal dialog**, so you can save a copy before removing
  anything.

## Notes

- **Backup files and the on-device model are separate.** Only the Backups group deletes snapshots
  HydraFit wrote, and only Remove model deletes the model file; removing all app data keeps both.
- Removing a group is permanent. Use the safeguard of a recent backup — back up now, or an automatic
  snapshot — if you are unsure.
- Files from earlier versions open normally, and backups made here keep the same format as 0.9.3.
